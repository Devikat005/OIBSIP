 Thermal Studio — Temperature Converter
 
 A responsive temperature conversion web application built with HTML, CSS, and JavaScript.
 Thermal Studio provides a simple way to convert temperatures between Celsius, Fahrenheit, and Kelvin through a modern interface with subtle animations and a dark visual theme.<img width="1883" height="920" alt="Temperature-converter" src="https://github.com/user-attachments/assets/14ae2a6d-f0a5-4e02-89d2-38f77010eaab" />

Features

   •Convert temperatures between Celsius, Fahrenheit, and Kelvin.

   •Display conversion results instantly.

   •Validate temperature inputs.

   •Prevent temperatures below absolute zero.

   •Responsive design for different screen sizes.


Technologies Used

    •HTML5
  
    •CSS3
  
    •JavaScript

 Conversion Formulas

    •Celsius to Fahrenheit: °F = (°C × 9/5) + 32
  
    •Fahrenheit to Celsius: °C = (°F − 32) × 5/9
  
    •Celsius to Kelvin: K = °C + 273.15
  
    •Kelvin to Celsius: °C = K − 273.15
